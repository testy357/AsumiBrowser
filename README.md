# あすみちゃん専用ブラウザ

**あすみちゃん専用ブラウザ**は、主にキャスで活動する個性派アイドル系配信者「あすみ。」ちゃんの配信鑑賞を目的に開発された、**ご本人公認の超特化型Windows向けブラウザ**です。

ツイキャス・ニコニコ生放送・Kick・Xなど、あすみちゃんの活動をチェックしやすくするための機能を備えています。

## 紹介動画

[▶ あすみちゃん専用ブラウザ 紹介動画（YouTube）](https://www.youtube.com/watch?v=MtKwAgIxdEg)

## 主な機能

- あすみちゃんの配信・活動先へアクセスできる専用ブラウザ
- 対応サイトの配信状況チェックと通知
- コメント入力を支援する機能
- 好みに合わせて変更できる各種スキン

※ 対応状況や機能の詳細は、紹介動画とインストールガイドをご確認ください。
