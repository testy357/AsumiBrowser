はじめに

「あすみちゃん専用ブラウザ」は、主にキャスで活動する個性派アイドル系配信者あすみちゃんの配信鑑賞に特化したご本人公認の専用ブラウザです。

動作環境

  • Windows 10 / 11（64ビット版）
  • Microsoft Edge WebView2 Runtime
  • .NET 8（Desktop Runtime相当の実行環境）

インストール・起動方法

  1. 配布ZIPファイルをダウンロードします。
  2. ZIPファイルを右クリックし、「すべて展開」を選択します。
  3. 展開されたフォルダ内の AsumiBrowser.exe をダブルクリックします。
インストーラーはありません。ZIP内から直接起動せず、必ずフォルダ全体を展開してください。フォルダ内のファイルは削除・移動せず、そのまま使用してください。

更新するとき

アプリを終了してから新しい配布ファイルを展開してください。設定やデータの保存場所はバージョンによって異なる可能性があるため、旧フォルダはすぐに削除せず、必要なデータをバックアップしてください。

主な機能

配信ページへのアクセスツイキャス・ニコニコ生放送・Kick・Xなどの関連ページをまとめて利用。
配信チェックと通知対応サイトの配信状況を確認し、設定に応じて通知。
コメント入力の補助定型文や弾幕など、コメント入力を便利にする機能。
選べるスキン気分に合わせて画面のデザインを切り替え。

紹介動画もご参照ください：あすみちゃん専用ブラウザ 紹介動画（YouTube）

※ 機能の利用可否や動作は、配布バージョン、設定、各サイトの仕様によって異なります。

起動できない場合

① WebView2 Runtimeが不足している場合

次のMicrosoft公式サイトを開き、「Evergreen Bootstrapper」をダウンロードして実行し、インストールしてください。

Microsoft Edge WebView2 公式ダウンロードページ

完了後、もう一度 AsumiBrowser.exe を起動してください。

※ Windows 11では通常インストール済みです。

② .NETのインストールを求められた場合

本ソフトには通常、必要な.NET実行環境が同梱されているため、追加インストールは不要です。

それでも.NETが必要というメッセージが表示された場合は、Microsoft公式サイトから .NET 8 Desktop Runtime（Windows x64） をインストールしてください。

Microsoft .NET 8 公式ダウンロードページ

「SDK」や通常の「.NET Runtime」ではなく、「.NET Desktop Runtime」を選んでください。

③ Windowsの警告が表示される場合

個人開発ソフトのため、Windowsから「WindowsによってPCが保護されました」などの警告が表示される場合があります。

配布元が正しいことを確認し、信頼できる場合に限り、表示される「詳細情報」から実行を選択してください。

④ それでも起動できない場合

ZIPを展開せずに直接EXEを実行していないか、ファイルが不足していないか確認してください。解決しない場合は、表示されたエラーメッセージを添えて配布元にご連絡ください。
